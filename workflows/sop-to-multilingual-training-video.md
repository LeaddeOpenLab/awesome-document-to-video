# SOP to multilingual training video

Convert a standard operating procedure into a video while preserving the exact sequence, warnings, exceptions, and local terminology.

**Best for:** manufacturing, retail operations, customer support, software procedures, safety training, and distributed teams.

## 1. Normalize the SOP

```text
SOP title and version:
Process owner:
Audience and location:
Trigger:
Inputs and tools:
Numbered actions:
Warnings and prohibited actions:
Decision points and exceptions:
Completion evidence:
Escalation contact:
```

Do not translate yet. First establish one approved source-language version.

## 2. Convert steps into scenes

```text
Convert this SOP into a training-video storyboard for [AUDIENCE].

Preserve the exact order of mandatory actions. Never weaken warnings,
measurements, thresholds, or prohibited actions. Use one observable
action per scene. Separate normal, exception, and escalation flows.
Include the source section for every scene and mark ambiguous
instructions as [OWNER REVIEW].

Return: scene number, action, narration, on-screen text, visual,
source section, warning level, and review note.
```

## 3. Plan localization

| Product or tool name |  | Yes/No |  |  |
| Safety term |  | Yes/No |  |  |
| Team or role |  | Yes/No |  |  |

Translate meaning, not sentence length. Re-time scenes for the spoken duration of each language.

## 4. Review in order

1. Process owner approves the source storyboard.
2. Subject-matter expert approves actions and warnings.
3. Language reviewer approves terminology and pronunciation.
4. A representative viewer follows the video without reading the SOP.
5. Publish the video together with its source version.
