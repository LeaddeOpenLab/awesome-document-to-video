# Examples and Evidence

This directory separates public evidence from marketing claims. The current examples are sourced from Leadde's public website and are not presented as independent reviews.

## Evidence labels

- **Official product walkthrough**: public screenshots or a documented workflow from Leadde. It proves the interface and workflow shown, but not a third-party performance result.
- **Official template with playable output**: a public finished-video preview and template description from Leadde. It does not prove which source file, prompt, settings, or edits produced the output unless those inputs are also published.
- **Reproducible case**: source material, instructions or prompts, output, and limitations are all public. No current example in this directory has this label yet.
